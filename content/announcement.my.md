Gemini tool နဲ့ Google Docs မှာရှိတဲ့ standard translator က စာသားတွေကို ကမ္ဘာလုံးဆိုင်ရာအဆင့်ကို ချက်ချင်းနီးပါးနဲ့ အနည်းဆုံးကုန်ကျစရိတ်နဲ့ ချိန်ညှိနိုင်အောင် ခွင့်ပြုပေးခဲ့ပါတယ်။ ကျွန်တော့်ရဲ့ကိုယ်ပိုင် batch processing script ကြောင့် သင့်ရဲ့စာရွက်စာတမ်းကို လူကိုယ်တိုင်ဝင်ရောက်စွက်ဖက်စရာမလိုဘဲ ဘာသာစကား ၁၀၀ ကျော်နဲ့ မြန်မြန်ဆန်ဆန် ဘာသာပြန်ပေးနိုင်တဲ့ ဝန်ဆောင်မှုကို ပေးဆောင်ပါတယ်။  
ဘာကြောင့်အလုပ်လုပ်တာလဲ-  
* အလွန်မြန်ဆန်သော- ဘာသာစကား ၁၀၁ မျိုးကို မိနစ် ၁၅ အတွင်း (စကားလုံး ၄၈၀၀၀ ရှိသော စာရွက်စာတမ်းအတွက် ဘာသာစကားတစ်ခုလျှင် ≈ ၉ စက္ကန့်)။  
* တိုးချဲ့နိုင်မှု- ခေါင်းစဉ်များ၊ စာရင်းများ၊ ဇယားများနှင့် ရုပ်ပုံများကို ထိန်းသိမ်းထားသည်။  
* ငွေစုခြင်း- စာအုပ်တစ်အုပ်ကို ဘာသာစကား ၁၀၁ မျိုးသို့ ဘာသာပြန်ဆိုခြင်း၏ ကုန်ကျစရိတ်မှာ ယူရို ၅ / ဒေါ်လာ ၆ ခန့်သာရှိသည်။  
အောက်တွင် သင့်လက်ရာ၏ ၁၀၁ ခုမြောက် ဘာသာပြန်ဆိုချက်ကို မှာယူရန်အတွက် အပြည့်အစုံ ညွှန်ကြားချက်များနှင့် စည်းကမ်းချက်များကို သင်တွေ့ရပါမည်။
